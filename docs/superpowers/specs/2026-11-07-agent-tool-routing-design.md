# 管束 Agent 工具路由设计

## 目标

配置 DeepSeek 后，自然语言请求由模型结合当前参数、元件统计和真实布管字符图选择白名单工具；程序不再先按关键词生成固定方案。模型只能提出参数修改、元件布置、换热管增删和界面操作，坐标解析、几何校验、预览及最终执行仍由现有程序负责。

## 约束与选择

- 明确的“确认方案、放弃方案、保留、撤销”等本地控制命令立即执行，避免多一次网络请求。
- 其它请求在配置 API 时全部交给 Agent；未配置 API 时保留当前离线关键词能力。
- 把 `TubeLayoutPage.plan_view_text()` 交给模型，使其能按真实行列号选择管孔。
- 移除模型无动作时自动补固定删管/元件方案的兜底；信息不足时允许模型询问用户。
- 模型给出的具体行列号必须经过现有 `parse_hole_ops` 和 `centers_for_refs` 校验，并继续显示待确认卡片。

## 非目标

- 不允许模型直接写坐标或数据库。
- 不修改现有图形计算、干涉校验和“确认执行”流程。
- 不承诺执行尚未封装为白名单工具的任意操作。

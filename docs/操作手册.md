# 管束 AI 审核助手操作手册

这份手册按“第一次使用电脑也能操作”的方式写。正常使用只需点击开始、审核参数和确认下一步。

## 一、打开程序

进入 `DongLanpec-Agent-Demo` 文件夹，双击 **启动管束设计助手.cmd**。

如果启动失败，黑色窗口不会立即关闭，会显示原因。常见情况是电脑没有可用的 Python/PyQt5；当前开发机默认使用 `D:\ProgramData\anaconda3\python.exe`。

## 二、第一次试用

1. 点击左侧 **开始管束设计**。
2. 等待审核预览出现。

Demo 已内置模拟上游数据、程序默认值和历史元件方案，不需要选文件、设备、产品型式或 DN。

## 三、是否必须设置 API Key

不必须。

- 不设置：程序使用离线审核流程，仍可装载模拟上游数据、参考历史方案、修改参数、审核并保存。
- 设置 DeepSeek：点击左侧 **AI 设置**，粘贴 API Key，保存后重新点击“开始管束设计”。模型只接收已经筛选、限制长度的证据片段。

默认服务地址是 `https://api.deepseek.com`，默认模型名是 `deepseek-v4-flash`。若账号实际开放的模型名不同，可展开“更多设置”修改。

勾选“记住密钥”时，密钥使用当前 Windows 账户加密；换一个 Windows 账户不能解密。旧版 Demo 的百炼设置不会被当成 DeepSeek 密钥使用。

## 四、怎么看参数来源

预览中每一行都有“来源”和“证据/说明”：

- **模拟上游数据**：代表前面模块已经保存、由总 Agent 路由过来的值；
- **程序默认值**：按产品型式得到的默认值；
- **文件明确要求**：DeepSeek 从当前设备文件中提取的候选修改，仍需人工确认；
- **历史建议值**：文件没有元件信息时，参考同型式、邻近 DN 的演示历史方案；
- **人工修改**：你在表格中改过的值；
- **联动计算**：程序根据其他参数自动计算，灰色显示，不能直接改。

问题句、备选项和互相冲突的文件内容不会自动覆盖参数，会保留在执行记录或冲突信息里。

如果同一参数出现互相矛盾的文件值，本阶段审核会失败并显示两边证据。你可以直接修改为最终采用值，或点击“我已阅读冲突并人工处理”，然后必须重新审核。

## 五、审核和修改——最重要的操作

四个阶段都遵循同一个流程。Agent 准备好数据时会在对话下方显示审核预览；可点击 **收起预览**，之后用左侧 **查看预览** 重新打开：

1. 检查预览参数，可以直接双击“参数值”修改。
2. 每次修改后，状态立即变成 **待审核**，以前的审核结果作废。
3. 点击 **审核本阶段**。
4. 如果不通过：
   - 错误参数单元格变红；
   - “审核结果”显示错误原因；
   - 有安全推荐值时，下方出现“采用 ××”按钮。
5. 可以手工改，也可以一键采用推荐值。
6. 采用推荐值后不会自动通过，必须再次点击 **审核本阶段**。
7. 直到界面显示 **审核通过，等待你确认**。
8. 再检查一遍，点击 **确认并进入下一步**。

“审核通过”和“用户确认”是两个不同闸门。只审核通过但没有点击确认，不会保存、不会进入下一阶段。

## 六、四个审核阶段

1. **管板型式**：产品型式、DN、管板节点参数和布管限定圆 DL。
2. **布管与元件**：管程与分程、管径/壁厚/中心距、隔板相邻管中心距、拉杆、旁路挡板、防冲板。
3. **管-板连接**：连接方式、焊接结构、管板厚度和焊接计算长度。
4. **轴向设计**：换热管长度、伸出长度、折流板距管板距离、间距和厚度。

修改较早阶段会撤销后续阶段的已通过状态，避免下游使用过期参数。

需要回看时点击 **返回上一阶段**。如果修改已确认阶段，其后所有阶段自动失效，必须重新审核。也可在底部对话框输入“换热管中心距 S 改为 34”，Agent 会修改当前阶段预览并要求重新审核。

## 七、保存在哪里

每次点击“确认并进入下一步”，当前阶段的审核快照写入独立演示数据库。四个阶段全部确认后，设计状态改为“已完成”。

数据库默认位置：

`%LOCALAPPDATA%\DongLanpecAgentDemo\tube_agent_demo.sqlite3`

保存内容包括参数、来源、证据短摘录、冲突信息、版本和审核事件。不复制整份输入文件，也不写入 DongLanpec 生产数据库。

左侧 **历史方案** 可以只读查看保存内容和各阶段快照。需要继续修改时选择“基于此方案创建新版本”；旧版本不会被覆盖。

## 八、当前 Demo 边界

- Demo 使用内置模拟数据。正式软件接收总 Agent/数据空间流转的数据，并从数据库读取前置参数。
- 重点元件为拉杆、旁路挡板、防冲板；折流板/支持板以参数和轴向信息展示。
- Demo 只验证数据流转、提取、审核、联动和保存闭环，不生成可交付的真实布管坐标。
- “审核通过”表示 Demo 已实现的共用规则通过；界面会同时提示型式专用工程规则尚未全部移植，仍由用户在最终确认闸门中判断。
- 正式接入生产系统前，还需单独完成生产数据库只读/写入适配、权限审批和完整工程规则验收。

## 九、快速测试审核功能

打开 [完整设计测试示例.txt](../完整设计测试示例.txt)，按里面的值逐项修改，即可看到标红、原因、推荐值、重新审核和确认保存全过程。

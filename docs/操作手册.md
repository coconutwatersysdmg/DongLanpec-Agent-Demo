# 管束 AI 审核助手操作手册

这份手册按“第一次使用电脑也能操作”的方式写。正常使用只需点击开始、检查参数和保留。

## 一、打开程序

进入 `DongLanpec-Agent-Demo` 文件夹，双击 **main.py**（或在文件夹里运行 `python main.py`）。

如果启动失败，请确认电脑装有可用的 Python/PyQt5；当前开发机默认使用 `D:\ProgramData\anaconda3\python.exe`。

## 二、第一次试用

1. 程序一运行就会**自动读取数据库并生成设计草稿**，无需再点“开始管束设计”。
2. 等待 Agent 提示“四个阶段的设计草稿已生成”；界面会按产品型式停在“管板型式”或“布管”阶段。

Demo 已内置模拟上游数据、程序默认值和历史元件方案，不需要选文件、设备、产品型式或 DN。

生成草稿后默认保持聊天界面。需要看表格时点击左侧 **查看预览**；也可以先在底部直接描述修改要求。

## 三、是否必须设置 API Key

不必须。

- 不设置：程序使用离线流程，仍可装载模拟上游数据、参考历史方案、修改参数并保存。
- 设置 DeepSeek：点击左侧 **AI 设置**，粘贴 API Key，保存后重新点击“开始管束设计”。模型只接收已经筛选、限制长度的证据片段。

默认服务地址是 `https://api.deepseek.com`，默认模型名是 `deepseek-v4-flash`。若账号实际开放的模型名不同，可展开“更多设置”修改。

勾选“记住密钥”时，密钥使用当前 Windows 账户加密；换一个 Windows 账户不能解密。旧版 Demo 的百炼设置不会被当成 DeepSeek 密钥使用。

配置 DeepSeek 后可以正常问答，也可以使用更自然的说法补充设计要求。模型只生成回复和候选修改，不能直接保存数据库。没有 Key 时仍可使用“折流板间距改成 500”这类明确的基础修改指令；无法识别时程序会如实提示当前处于离线模式。

## 四、怎样和管束助手对话

可以直接输入：

- `换热管中心距改为 34`
- `旁路挡板数量改成 3`
- `折流板间距调整为 500`
- `帮我检查一下这些参数是否合理`
- `删除离隔板槽最近的两行换热管`
- `恢复刚才删除的换热管`
- `取消全选`
- `选中最外一圈的换热管`（= 每行最左、最右各一根，加最上、最下一整排）
- `输出所有拉杆坐标`
- `将所有拉杆恢复为换热管`
- `给我输出所有换热管绝对坐标`

输入完成后按 **Enter** 发送；需要在同一条消息中换行时按 **Shift+Enter**。

四个页面都可以随时打开和修改，没有“必须先保留上一页”的前置条件。Agent 会在聊天里显示“阶段、参数、原值 → 新值”。

修改只读参数、联动计算参数或不存在的参数时，Agent 会说明没有执行。所有对话修改都只是草稿，仍需进入相应阶段检查并点击 **保留**。

## 五、怎么看参数来源

预览中每一行都有“来源”和“证据/说明”：

- **模拟上游数据**：代表前面模块已经保存、由总 Agent 路由过来的值；
- **程序默认值**：按产品型式得到的默认值；
- **文件明确要求**：DeepSeek 从当前设备文件中提取的候选修改，仍需人工确认；
- **历史建议值**：文件没有元件信息时，参考同型式、邻近 DN 的演示历史方案；
- **人工修改**：你在表格中改过的值；
- **联动计算**：程序根据其他参数自动计算，灰色显示，不能直接改。

问题句、备选项和互相冲突的文件内容不会自动覆盖参数，会保留在执行记录或冲突信息里。

如果同一参数出现互相矛盾的文件值，点击保留后会显示两边证据。你可以直接修改为最终采用值，或点击“我已阅读冲突并人工处理”，然后再次点击保留。

## 六、检查和保留——最重要的操作

四个阶段都遵循同一个流程。Agent 准备好数据时会在对话下方显示参数预览；可点击 **收起**，之后用左侧 **查看预览** 重新打开：

1. 检查预览参数。输入方式与正式管束程序一致：
   - 带下拉箭头的值直接选择；
   - 换热管外径和公称长度既可下拉选择，也可直接输入；
   - 其余白色参数值双击后输入；
   - 灰色参数来自上游或联动计算，不能直接修改。
2. 修改完成后点击 **保留**。
3. 程序会自动检查参数。如果有问题：
   - 错误参数单元格变红；
   - 下方显示错误原因；
   - 有安全推荐值时，下方出现“采用 ××”按钮。
4. 可以手工改，也可以一键采用推荐值，然后再次点击 **保留**。
5. 参数没有问题时会弹出确认框；点击确认后保留本页，并可继续检查任意其它页面。

## 七、四个审核阶段

1. **管板型式**：产品型式、DN、管板节点参数和布管限定圆 DL。
2. **布管与元件**：管程与分程、管径/壁厚/中心距、隔板相邻管中心距、拉杆、旁路挡板、防冲板。
3. **管-板连接**：连接方式、焊接结构、管板厚度和焊接计算长度。
4. **轴向设计**：换热管长度、伸出长度、折流板距管板距离、间距和厚度。

修改已经保留的页面只会撤销该页面自己的确认状态，其它页面保持不变；程序仍会执行已有的参数联动和校验。

### 左侧参数表（控件逐条照搬正式程序）

- **普通参数**（中心距、壁厚、切口率…）就是**单元格里的文字**：**单击参数值格就直接进编辑**（双击同样可以），
  回车或点别处生效；不是一格一个输入框。公称直径 DN 灰字不可改（点它不会弹出输入框）。
- **下拉框**（是否以外径为基准 / 管程程数 / 排列方式 / 切口方向 / 拉杆形式…）只能从选项里选，不能手输；
  样式与正式程序一致：白底、1px 灰边、直角、右侧灰色小三角，滚轮不切选项。
- **“输入 + 下拉”两用的两个参数**（正式程序就是这么做的）：
  - `换热管外径 do`：可以从 10/12/14/16/19/20/22/25/30/32/35/38/45/50/55/57 里选，也可以直接敲小数（如 25.4、19.05）；
  - `换热管公称长度 LN`：可以从 1000…12000 里选，也可以直接敲整数。
- **换热管排列方式**用正式程序 2026-11 最新文案：正三角形排列（30°）/ 转角正三角形排列（60°）/
  正方形排列（90°）/ 转角正方形排列（45°）；库里仍存“正三角形/转角正三角形/正方形/转角正方形”，
  传给布管计算的 `LB_RangeType` 仍是 1/0/2/3。
- 折流板类型、隔条位置尺寸 W/Wy/Wx、吊环螺钉规格在正式程序里是普通单元格，这里也给普通单元格（不是下拉）。
- **列宽**：参数名按最长的可见名字给宽（“分程隔板两侧相邻管中心距（竖直）”不会被省略号截断），
  单位列按 `单位 / mm / ° / 个` 自适应；窗口拉窄也不会把单位列挤出右边（没有横向滚动条）。

### 布管页怎么点（与正式程序一致）

- **选点**：单击换热管就选中，再点一下取消；点第二根不会把第一根顶掉（可以一直累加）。**普通拉杆和换热管同性质**，也能这样多选，还能直接当防冲板/挡板的参照管。
- **编辑元件**：双击已布置的防冲板、挡板、滑道、拉杆、挡管或吊环螺钉，打开对应参数弹窗；确认后图形立即更新，可用“撤销”恢复。
- **防冲板干涉**：布置或编辑防冲板时，板体/壳侧弓形影响区内的换热管孔会删除；同时命中的拉杆也会移除，管孔保持删除状态，撤销可恢复。
- **隔条修正提示**：支持本地分程计算的形式会在“拉杆标准要求数量”下显示按 Snv/Snh 修正隔条尺寸的提示；DLL 布管输出不提供这些修正量时，不会用 DLL 的 W 值替代提示。
- **右键**：清空所有选中（取消筛选）；拖框可一次选中一片管孔；Ctrl+滚轮缩放。
- **对称分布**（图形右上角，默认勾选）：勾选时选中 1 根，布置拉杆/删除时自动补出上下左右 4 个镜像点；取消勾选只按管程程数补单轴镜像（2 管程补上下、4/6 管程补左右）。中间挡板、中间挡管同样会在另一侧补一块。
- **中间挡管**（照正式程序 `center_dangguan`）：必须在**同一隔板槽两侧各选一根**参照管（2 管程选水平中心线上下两根，4/6 管程选竖直中心线左右两根）。挡管落在两管连线与隔板槽轴线的交点上，不是两管中点；两管在同一侧会提示“所选参照管位置不合理，请在同一隔板槽两侧各选一个参照管!”。
- **中间挡板**（照正式程序 `center_dangban`）：只能在**隔板槽两侧第一排**各选一根换热管，板长 = 两管中心距 − do − 2×名义孔桥宽度。选错会提示“只能选择隔板槽两侧第一排换热管孔作为中间挡板的参照管！”，跨度过大会提示“所选的2个换热管范围过大，请重新选择！”。
- **旁路挡板 / 拉杆 / 自由拉杆**：勾选“对称分布”时，选 1 根参照管就按 4 个象限各铺 1 个（共 4 个）。
- **旁路挡板宽度**由程序算：取同排最外侧参照管到折流板外径圆边的距离，减去名义孔桥和 do/2，板从圆边向里伸，
  外边缘压在圆上，所以整块板（含厚度）都在大圆里；算出来的宽度会写回“旁路挡板宽度”参数，方案卡上只读显示。
- **中间挡管 / 中间挡板 的对称**：勾“对称分布”时，一对参照管会在隔板槽另一侧再补一对（各出 2 个）；
  压在竖直中心线上的那一对镜像就是自己，程序会优先挑偏心的一对，保证两侧都有。
- **AI 方案卡**：卡片上给出“第几行第几列 + 绝对坐标”，行号列号、板厚、折边角、**形式**都能直接改；改了形式，卡片里的参数项和标题会立刻跟着变。填了不存在的管孔会标红并锁住“确认布置”。
- **删 / 补换热管**：直接说“删除离隔板槽最近的两行换热管”“把最外圈那几根去掉”“恢复刚才删除的换热管”，
  助手会先出一张“换热管调整方案”卡：只写“删哪一片、几排、共几根 + 具体第几行第几列”，图上同时把要动的管孔圈出来，
  点**确认执行**才动图，点**放弃**图纸不变。模型只给位置区域（隔板槽两侧 / 靠近壳壁 / 中心 / 上 / 下 / 左 / 右 / 选中 / 已删除），
  具体管孔一律由程序按当前布管结果算。
- **“最外层/最外圈”的口径**：布管外轮廓——**每行最左、最右各一根 + 最上、最下一整排全取**
  （正三角形布管 630 孔时是 84 根），不是按半径剥出来的一圈，也不是从中间穿过去的一条锯齿；
  只取每行两端时，左右两条弧爬到 0°/180° 就断了，顶上（6 根）和底下（6 根）那一排的中间几根空着，
  所以顶排、底排整排都算外轮廓，轮廓才是闭合的圈。卡片上会写清
  “布管外轮廓：每行最左、最右各 1 根，加最上、最下一整排”，并列出每根的行号列号，确认前先在图上圈出来给你看。
- **删掉的管孔留在图上**：用红色虚线小圆圈 + 小叉标出（照正式程序在“被删除的换热管位置补画提示圆”的做法），
  点一下就能选中，再说“恢复选中的换热管”即可还原；说“恢复全部”则把所有删掉的管一起还回来。
- **界面上的事都能让它做**：取消全选 / 全选 / 选中最外一圈 / 反选 / 撤销 / 重绘 / 全屏 / 切到某个阶段 / 保留 /
  开关“对称分布” / 删除选中的元件 / 输出坐标。模型只写“做哪个动作”，落点、数值全部由程序执行，所以不会编数据。
- **每个元件有自己的数据字典**：说“输出所有拉杆坐标”给的是**拉杆**表（形式、直径 φ、所在行号列号、X、Y），
  不会拿换热管表糊弄；中间挡板/旁路挡板/防冲板同理，各自给自己的板长、板厚、形式、折边角。
- **元件和换热管可以互相转**：说“把所有拉杆恢复为换热管”“删除所有中间挡管”，程序会把该元件删掉，
  并把当初占用的管孔还给换热管（图上管子立刻回来）。
- **拉杆一次最多 40 根**：说“所有拉杆”这类话是查询，不会变成几百根的布置方案；真要布置就写清根数。

需要回看时直接点击左侧阶段名称。起始阶段随产品型式变化：BEM / NEN / AEM / NEN(H) 打开就停在“管板型式”，其余型式停在“布管”（与正式程序 `My_Piping` 一致）。未到达的阶段不能提前打开。修改旧阶段后再次点击 **保留**，程序会从下一阶段继续。也可在底部对话框输入“换热管中心距 S 改为 34”。

## 八、保存在哪里

每次确认保留后，当前阶段的参数快照写入独立演示数据库。四个阶段全部保留后，设计状态改为“已完成”。

数据库默认位置：

`%LOCALAPPDATA%\DongLanpecAgentDemo\tube_agent_demo.sqlite3`

保存内容包括参数、来源、证据短摘录、冲突信息、版本和审核事件。不复制整份输入文件，也不写入 DongLanpec 生产数据库。

左侧 **历史方案** 可以只读查看保存内容和各阶段快照。需要继续修改时选择“基于此方案创建新版本”；旧版本不会被覆盖。

## 九、当前 Demo 边界

- Demo 使用内置模拟数据。正式软件接收总 Agent/数据空间流转的数据，并从数据库读取前置参数。
- 重点元件为拉杆、旁路挡板、防冲板；折流板/支持板以参数和轴向信息展示。
- Demo 只验证数据流转、提取、审核、联动和保存闭环，不生成可交付的真实布管坐标。
- 点击保留时只检查 Demo 已实现的共用规则；正式接入前仍需补齐型式专用工程规则。
- 正式接入生产系统前，还需单独完成生产数据库只读/写入适配、权限审批和完整工程规则验收。

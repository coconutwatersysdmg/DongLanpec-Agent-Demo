# 设计人员操作手册

## 打开与第一次设置

双击同目录的 **启动管束设计助手.cmd**。

第一次使用真实AI，点右上角 **AI设置**，把阿里云百炼的完整API Key粘贴到密码框，再点“保存并返回”。默认北京地域、qwen-plus模型。其他地域才需要展开“更多设置”。密钥不用发到聊天里。

“记住密钥”使用Windows账户加密，文件保存在 `%APPDATA%\DongLanpecAgentDemo\settings.json`，不是明文。关闭后再打开会自动加载；换Windows账户或电脑不能直接解密。不想记住可取消勾选。

## 日常操作只有三步

1. 在右侧写下设计要求，也可以先点 **填入完整设计示例**。
2. 点 **开始设计**，左侧参数、中间布管图和右侧统计自动更新。
3. 查看结果。不满意点 **撤销本次操作**，满意点 **保存设计方案**。

你不需要读JSON，也不用逐个选孔放拉杆。**执行详情**默认收起，是排查问题时用的。

## 第一次演示怎么做

想先熟悉而不联网：下拉框选 **离线操作演示 · 固定示例** → **填入完整设计示例** → **开始设计**。

会看到13项参数被填入，原算法生成1122个初始管孔，再布置8根拉杆、2块旁路挡板、1块防冲板。为板件预留空间并保持U形管上下配对后，剩余972个换热管位置。这个数字是管孔/腿位置，不直接等同U形管根数。

离线演示只支持固定的这段描述，没有调用AI，但填参、布管和元件工具确实执行了。要用自己的话设计，切回 **百炼AI · 按你的要求设计**。

需要连续测试不同设计时，打开程序目录下的 **完整设计测试示例.txt**。里面有8组可以直接复制的输入，覆盖多种产品型式、单/双管程、四种管子排列方式以及不同元件组合。

## 一段可以直接用的设计要求

```text
设计一台AEU换热器，采用内径基准，公称直径1300毫米，2管程，1壳程。
布管限定圆1284毫米，换热管外径25毫米，壁厚2毫米，管长4.5米，
管中心距32毫米，转角正方形排列，跨中布置。
分程隔板两侧相邻管中心距（竖直）100毫米。
先布管，再左右布置2块旁路挡板，宽40毫米、厚3毫米；
上部距中心500毫米布置1块防冲板，宽300毫米、厚6毫米；
最后外围对称布置8根拉杆，直径16毫米。
```

原有参数已经在左侧时，可以说：

> 按当前参数布管，然后外围对称放8根直径16毫米的拉杆。

已有布管，想增加拉杆，可以说：

> 再增加4根拉杆，外围对称，直径16毫米。

元件工具的数量是**本次新增数量**。如果要重做整套布置，先撤销或重布管，再给出新要求。重布管会清除旧元件；修改几何参数也会清空旧布管，需要重新布管。

## 也可以用你熟悉的按钮

- 直接在左侧改参数，再点 **布管**。
- 布管完成后点 **自动布置元件**，选元件、数量、尺寸，程序自动选位置。
- 鼠标滚轮缩放布管图，按住左键拖动，双击或点 **适应窗口** 恢复全图。
- 蓝色细线连接相邻换热管圆心，判定规则与原管束界面一致；旁路挡板为纯蓝色，防冲板为深蓝色，折流板图例为黄色。
- **撤销本次操作**可恢复一次手动操作，或整轮助手操作前的参数、管孔和元件。
- **停止**会阻止后续步骤；当前网络请求需要等返回/超时。已完成步骤保留，想全部恢复可点撤销。

## 这个版本支持的范围

| 设计项 | 支持情况 |
| --- | --- |
| 基准与分程 | 内径基准、1/2管程；其他情况会提示，不擅自选型 |
| 拉杆 | 占用已有孔位；外围对称、上/下/左/右区域；U形管2管程需外围对称并保持上下配对 |
| 拉杆直径 | 可指定；不指定时沿用原程序推荐档位并记录来源 |
| 旁路挡板 | 左右2块或左右上下成对4块；需要明确宽度、厚度 |
| 防冲板 | 上部或下部1块平板；需要明确宽度、厚度、距中心距离 |
| 缺参数或冲突 | 给出中文提示；该失败步骤不会留下半完成设计 |
| 保存 | 保存独立方案文件，包含参数、坐标、元件和执行记录，不含密钥 |

布管直接复用原工程算法。元件采用独立Demo几何选位与预留策略，检查管孔/元件干涉及U形管配对，**尚未接入原软件所有元件标准、制造和强度校核**，用于验证智能设计操作，不直接作为生产出图结论。

## Agent到底体现在哪里

真实AI模式不是只把文字转成JSON。模型会先读当前设计，再选择填参、布管、放元件和检查工具。每个工具执行后，把实际结果返回给模型，它再决定下一步；信息不足时停止并提示补充。设计人员只看结果和提示即可。

程序会核对是否真的布管、元件是否遗漏、数量是否达到要求，以及是否完成检查。模型单纯说“已经完成”不能把未执行的设计标成成功。

如需给师兄看技术过程，展开 **执行详情**，可以看到真实工具名、参数和执行结果；这里展示操作记录，不展示或编造模型内部思维链。

## 连接失败怎么办

- 提示未配置：点“AI设置”填写完整密钥。
- HTTP401：检查密钥与服务地址的地域是否一致。
- HTTP403：检查业务空间与模型权限。
- HTTP404：检查模型名与服务地址。
- HTTP429：在百炼控制台检查额度或限流。
- 网络超时：网络恢复后重新点击；程序不会悄悄重试计费请求。

一轮设计可能多次调用模型，最多12轮。工具在本地执行；实际费用按百炼账号规则计费。调试时先用离线演示，不要根据余额截图推断可用额度。

真实模型接入协议已按[百炼Function Calling官方说明](https://help.aliyun.com/zh/model-studio/qwen-function-calling)实现。自动测试使用假密钥和模拟网络，未代替你发起真实计费调用；实际账号仍需本地联网验证。

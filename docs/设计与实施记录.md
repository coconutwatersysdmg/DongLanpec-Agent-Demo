# 面向设计人员的管束 Agent Demo

用户目标：在 DongLanpec 同级建立独立 Demo，界面沿用左参数、中布管图、右管孔统计的布局。设计人员用自然语言完成填参、布管、拉杆/旁路挡板/防冲板布置，不需要了解JSON或计算机知识。2026-10-20用户补充：便利优先，技术详情默认收起。

实现方式：PyQt5独立界面；引用同级DongLanpec中的本地布管算法，不连接产品数据库。百炼Function Calling多轮调用白名单工具，执行结果返回给模型继续判断。缺参数给出中文提示，工具失败不改变当前设计，组件只能在布管后放置；结果可撤销、导出。

工具：read_design、set_parameters、layout_tubes、place_components、inspect_design。填参必须引用用户原文；不得执行模型给出的代码或SQL。元件使用Demo几何策略，拉杆占用已有孔位，板件预留空间并清除相交管孔，检查圆内边界与元件冲突。这不是原软件所有制造/强度校核的替代。

第一版范围：内径基准，1/2管程；拉杆（外围对称/上/下/左/右）、左右2/4块旁路挡板、上/下1块平板防冲板。多管程复杂分程、其他元件和外径基准先清楚提示，不能伪装完成。API Key可选择Windows账户加密记住；不写明文密钥。

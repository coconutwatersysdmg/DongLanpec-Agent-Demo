# 管束 AI 审核助手 Demo

这是与 `DongLanpec` 交付工程完全分开的演示程序。界面默认只显示一个类似 Codex 的对话窗口，Agent 需要人工审核时才展开右侧参数抽屉。Demo 用来验证：

`输入文件 → 设备确认 → 管束 Agent 提取/建议 → 四阶段人工审核 → 独立 SQLite 保存`

它不会向生产项目加入 AI 代码，不连接生产 MySQL，也不声称完成真实布管坐标设计。

## 快速开始

双击 [启动管束设计助手.cmd](启动管束设计助手.cmd)。

第一次建议这样试：

1. 在对话输入区下方点击“使用示例资料”；
2. 选择一个设备位号，确认产品型式和 DN；
3. 点击“交给 Agent 处理”；
4. 待审核抽屉自动展开后，修改任意参数并点击“审核本阶段”；
5. 审核失败时查看红色单元格、原因和推荐值；
6. 可以点击“一键采用推荐值”，但采用后必须再次审核；
7. 全部通过后点击“确认并进入下一步”，这时才保存本阶段。

资料扫描和 DeepSeek 调用在后台执行，界面不会被网络等待锁死；可点击“停止”。审核抽屉可随时收起，再用顶部“查看审核”打开。已确认阶段可以返回修改，程序会自动撤销依赖它的后续审核。右上角“历史方案”可只读查看旧版本，并复制成一个新版本继续审核。

Demo 里的资料选择只是为了给老师独立演示。正式软件的管束模块不重复上传文件，而是从总 Agent/数据空间接收流转数据，并从数据库读取前置模块参数。仓库中的 Pipeline 图描述的是这个正式流程，不是 Demo 内部实现。

完整说明见 [设计人员操作手册](docs/操作手册.md)。人工测试值见 [审核闭环测试示例](完整设计测试示例.txt)。

## AI Agent 能力

管束 Agent 不是一次文本问答。它会按顺序调用受控工具完成文件扫描、设备隔离、基础参数装载、证据检索、DeepSeek 结构化提取、历史方案查询、规则审核和审核快照提交。模型不能自行确认、不能绕过校验、不能执行任意 SQL。

默认模型名按需求设置为 `deepseek-v4-flash`，服务地址为 `https://api.deepseek.com`。如果账号控制台提供了不同的当前模型别名，可在“DeepSeek 设置 → 更多设置”中修改。没有密钥时仍能完整演示离线审核流程，并明确显示“未调用模型”。

## 数据位置

审核结果默认保存到：

`%LOCALAPPDATA%\DongLanpecAgentDemo\tube_agent_demo.sqlite3`

API Key 若选择记住，会使用当前 Windows 账户的 DPAPI 加密，代码、日志和截图中不保存明文。

演示库还保存输入文件名、解析状态和 SHA-256 哈希，用来确认某次审核实际依据的是哪一版文件；不会复制整份原文件。

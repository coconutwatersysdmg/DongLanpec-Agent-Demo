# 管束 AI 审核助手 Demo

这是与 `DongLanpec` 交付工程完全分开的演示程序。界面采用 Codex 式左侧导航和右侧对话；需要审核时，参数预览直接出现在对话主区。Demo 用来验证：

`模拟数据流转/数据库读取 → 管束 Agent 提取与建议 → 四阶段人工审核 → 数据库保存`

它不会向生产项目加入 AI 代码，不连接生产 MySQL，也不声称完成真实布管坐标设计。

## 快速开始

双击 [启动管束设计助手.cmd](启动管束设计助手.cmd)。

第一次只需两步：

1. 双击 **启动管束设计助手.cmd**；
2. 点击左侧 **开始管束设计**。

程序会自动读取模拟上游数据、默认值和历史元件方案，然后显示参数预览。用户只需修改参数并点击 **保留**，也可在底部对话框直接说“换热管中心距 S 改为 34”。

Demo 使用内置模拟数据；正式软件会从总 Agent/数据空间接收流转数据，并从数据库读取前置模块参数。

完整说明见 [设计人员操作手册](docs/操作手册.md)。人工测试值见 [审核闭环测试示例](完整设计测试示例.txt)。

## AI Agent 能力

管束 Agent 不是一次文本问答。它会按顺序调用受控工具完成数据接收、基础参数装载、证据检索、DeepSeek 结构化提取、历史方案查询、规则审核和审核快照提交。模型不能自行确认、不能绕过校验、不能执行任意 SQL。

默认模型名按需求设置为 `deepseek-v4-flash`，服务地址为 `https://api.deepseek.com`。如果账号控制台提供了不同的当前模型别名，可在“DeepSeek 设置 → 更多设置”中修改。没有密钥时仍能完整演示离线审核流程，并明确显示“未调用模型”。

## 数据位置

审核结果默认保存到：

`%LOCALAPPDATA%\DongLanpecAgentDemo\tube_agent_demo.sqlite3`

API Key 若选择记住，会使用当前 Windows 账户的 DPAPI 加密，代码、日志和截图中不保存明文。

演示库还保存输入文件名、解析状态和 SHA-256 哈希，用来确认某次审核实际依据的是哪一版文件；不会复制整份原文件。

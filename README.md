# 管束设计 Agent Demo

独立的管束设计演示程序：把正式软件 `DongLanpec` 的管束设计能力（65 项布管参数表、正式布管计算组件 `HE3DTB.dll`、
管孔坐标/元件/数量表、真实数据库读写）抽取到本目录内，用聊天界面驱动四个正式 Tab：

`管板型式 → 布管 → 管-板连接 → 轴向设计`

- **不导入**正式项目目录，不修改 `DongLanpec` 与 `DongLanpec - AI` 任何文件；需要的代码是**复制/重构**到本目录 `bundle/`。
- 原版布管模块完整副本位于 `modules/buguan/buguan_ziyong/`（含该模块资源与 DLL，逐文件与源目录校验一致）；它作为源程序快照保存，当前 Demo 页面仍运行 `bundle/` 实现。原版入口还依赖 DongLanpec 的产品管理/项目检查模块及数据库配置，未在本 Demo 中自动启动。
- 连接**正式数据库**（`产品设计活动库` / `元件库` / `配置库`），不建立模拟 SQLite 业务库。
- 布管图形与右侧管孔数量表是**真实交互**：整行/多行选择、框选、点击、删除、撤销、元件布置都会同时更新图形、表格与写库数据。
- 图形含正式程序同款**圆心连线**（按中心距 S 连接相邻管孔）；操作反馈只保留最新一条，不会刷屏。
- 左侧参数完全按正式程序规则**隐藏元件参数**（滑道/防冲板/中间挡板/吊环螺钉/拉杆/折流板…），
  改在“布置元件”时弹窗确认；管程分程形式直接**显示分程示意图**；图形/数量表**右键取消筛选**。
- **AI 能布置元件**：说“在靠壳壁的管孔上布置 4 根螺纹拉杆、直径 16”，AI 先给一版**布置方案卡**
  （元件 / 数量 / 选中的换热管 / 参数）。**方案的本质就是正式程序那一步“选管 + 参数”**：
  AI 只说清选哪几根，程序按当次真实布管结果落到具体管孔、并在图上先高亮出来；
  参数一列直接取参数表当前值（用户不动就是默认值），数值不由模型生成。
  点“确认布置”后落地，管孔数量同步刷新；点“布管”重算时按正式程序清空已布置元件。
- **方案卡可编辑**（就是正式程序那个“选管 + 参数”弹窗）：每根参照管按**第几行第几列**给出，
  行号列号可直接改，改完立刻显示该管的绝对坐标、图上高亮同步；填了不存在的管孔会标红并锁住
  “确认布置”；板厚、折边角等参数也能改，改过的值确认后写回参数表并据此落图。
- **左侧参数表的控件照搬正式程序**（`bundle/params.py` 的 `_SPECS` 对应 `My_Piping.special_params`）：
  普通参数是单元格内直接编辑（不是一行一个输入框）：**点一下参数值格就能改**（源程序同款 Excel 手感，
  双击同样可以），公称直径 DN 灰字不可改；单位列按内容自适应，窗口再窄也不会被挤出去；
  下拉框白底灰边直角 + 灰色三角、滚轮不切选项；`换热管外径 do`、`换热管公称长度 LN` 是**输入 + 下拉**两用
  （可选标准值，也可手敲 25.4 / 19.05 这种）；排列方式用最新文案“正三角形排列（30°）…”。
- **选管是累加式的**（同正式程序）：单击换热管切换该管的选中状态，点第二根不会顶掉第一根，
  再点一次取消；底部提示 1 根给绝对坐标、2 根给中心距；右键清空选中。
- **已布置元件可双击编辑**：防冲板、挡板、滑道、拉杆、挡管与吊环螺钉会打开对应参数弹窗；
  确认后重算相关图形并保留撤销能力。
- **元件布置规则照搬正式程序**：拉杆按 `judge_linkage` 关于 x/y/中心对称展开；中间挡管、中间挡板
  必须选**恰好 2 根参照管**；旁路挡板每个参照管 1 块、沿折流板切口方向到壳壁；滑道与吊环螺钉不选管、
  按参数沿管板外圆定位。
- **防冲板三种形式分开建**（`bundle/impingement.py`，照抄 `impingement_plate.build_impingement_plate`）：
  平板形＝一条线宽等于板厚的粗线（顶部连线向远离管板圆心侧平移、下半圆向下，中心连线两端各缩 do/2）；圆弧形＝**A-P-Q-B 折边梯形**
  （A/B 是两管沿连线法向让开 do/2+板厚/2 的点，折边高 H=max(S+1, do/2+6+1)，顶部长度 = 中心距 − 2H/tan折边角，
  为负则报参数异常）；焊接式＝靠 板宽 + 方位角(0°=顶部) + 至圆筒内壁距离 定位，A/B 落在壳体内壁圆上。
- **防冲板落位后自己删掉干涉换热管**（照抄 `build_impingement_plate` 之后的三个函数）：
  板体压到的管（折边形按 A-P、P-Q、Q-B 三段各算矩形带）＋**弦靠壳壁一侧的整片弓形区**，
  两块参照管保留；再按管程程数补镜像（2 管程 → 关于水平中心线，4/6 管程 → 关于竖直中心线）。
  同一影响范围内的拉杆也会移除；其管孔保持删除，编辑防冲板或撤销时状态一致。
- **隔条修正提示**显示在拉杆数量摘要下方：本地分程算法按 Snv/Snh 计算并提示 Wx/Wy 修正；DLL 输出不含这些极值时不以其 W 值冒充修正结果。
  删掉的管孔立刻从布管图与“管孔数量分布”里消失，撤销可恢复。
- **删 / 补换热管也是对话操作**：说“删除离隔板槽最近的两行换热管”“把最外一圈去掉”“恢复刚才删除的换热管”，
  先出一张“换热管调整方案”卡（删哪一片、几排、共几根 + 具体第几行第几列），确认后才动图。
  区域规则（`groove / outline / center / top / bottom / left / right / selected / removed`）全部由程序换算成真实管孔，
  **“最外层/最外圈”= 每行最左、最右各一根 + 最上、最下一整排**（正三角形 630 孔时 84 根），不会整片删光、
  也不是从中间穿过去的锯齿，顶部/底部那一排不会留缺口；
  删掉的管孔在图上留**红色虚线小叉**，还能再点选恢复。
- **界面上的事 Agent 都能做**：取消全选 / 全选 / 按区域选 / 反选 / 撤销 / 重绘 / 全屏 / 切阶段 / 保留 /
  开关“对称分布” / 删除选中的元件 / 输出坐标。
- **元件有自己的数据字典**：说“输出所有拉杆坐标”给的是**拉杆**表（形式、φ直径、所在行号列号、X、Y），
  不是换热管表；挡板给板长板厚，防冲板给形式/折边角/宽度。说“把所有拉杆恢复为换热管”，
  程序删掉拉杆并把占用的管孔还给换热管。外轮廓拉杆可按当前真实管孔一次全部布置，不再设 Demo 人工上限。
  模型只输出动作名（`ui_actions`），落点、数值、行号列号一律由程序按真实布管结果执行，所以既“百无禁忌”又不会编数据。
- **图形化界面固定在对话区上方**：窗口上下分割（上预览 / 下对话），对话再长都不用上翻看图，
  切换 Tab 仍在同一块预览区渲染。启动即**最大化铺满屏幕**（小屏也自适应），上下分割约 46/54：
  预览只留“刚好放得下布管页”的高度（≥430），剩下的全给对话；分割条可以自己拖。
  新消息/新卡片自动滚到最新一条（卡片比可视区高时从卡片顶部开始看）。
- 左侧参数表**“参数值”整列右对齐**（数字框与下拉框文字都靠右），与正式程序一致。

## 快速开始

```bash
python -m pip install -r requirements.txt
python main.py
```

或双击 `启动管束设计助手.cmd`。

启动后点左侧 **开始管束设计**：程序会读取正式库中前序模块已保存的数据，按四个 Tab 生成草稿；
每个 Tab 预览底部只有一个 **保留** 按钮；四个 Tab 全部保留后才会写库。

## 目录

| 路径 | 说明 |
| --- | --- |
| `main.py` | 入口（`--screenshot` 支持离屏截图，用于验收留证） |
| `window.py` | 聊天式主窗口、左侧四 Tab 导航、预览卡片、保留/写库流程 |
| `session.py` | 四个独立 Tab 的人工确认状态、全部确认后的单事务写库 |
| `models.py` | 四个正式 Tab 名称 |
| `bundle/page.py` | 布管页：参数表 + 布管图形 + 右侧管孔数量表 + 元件操作 |
| `bundle/engine.py` | 调用正式 `HE3DTB.dll` 计算布管，生成管孔坐标与关键尺寸 |
| `bundle/params.py` | 正式程序 65 项布管参数、控件类型与选项、联动映射 |
| `bundle/items.py` / `view.py` | 图元（换热管/拉杆/挡板/滑道…）与视图（缩放、框选、平移） |
| `bundle/hole_table.py` | 右侧“管孔数量分布”表（按行/按列、整行/多行选中、淡蓝高亮、右键取消筛选） |
| `bundle/widgets.py` | 分程形式示意图下拉框、元件参数确认弹窗（对标正式程序同名控件） |
| `bundle/placement.py` | AI 元件布置方案：元件白名单、选孔规则（外围对称/靠壳壁/均布/上下左右）、纯函数选孔（分行分列、相邻参照管成对、对称展开） |
| `bundle/impingement.py` | 防冲板三种形式的纯几何（平板形平移 / 圆弧形折边梯形 A-P-Q-B / 焊接式按方位角与内壁距离） |
| `bundle/stages.py` | 管板型式、管-板连接、轴向设计三个预览页 |
| `bundle/dll/` | `HE3DTB.dll`、`Newtonsoft.Json.dll`（正式程序自带组件副本） |
| `bundle/static/` | 正式程序示意图副本（分程形式、元件按钮、焊缝、管板形式等） |
| `db/production.py` | 正式数据库只读查询 + 单事务写库计划 |
| `ai_support/` | DeepSeek 客户端与结构化输出校验 |
| `tools/acceptance_check.py` | 102 项端到端自检（真实操作图形/表格，不写库） |
| `tests/` | 单元测试 + 端到端自检用例 |
| `docs/交付说明.md` | 交付清单、运行/配置/演示步骤、已验证与未验证项、数据库排错 |
| `legacy_demo/legacy_modules/` | 早期演示版本模块（已不被新实现引用，仅存档） |

## 数据库配置

默认按正式程序一致的方式连接：`localhost:3306`，用户 `root`，密码 `123456`，库 `产品设计活动库`。
可用环境变量覆盖（`db/production.py`）：

```
DONGLANPEC_DB_HOST / DONGLANPEC_DB_PORT / DONGLANPEC_DB_USER
DONGLANPEC_DB_PASSWORD / DONGLANPEC_DB_NAME
```

连接失败时界面会直接报错并给出排查步骤，**不会**回退到模拟数据库。

# 2026-11-06 · AI 能布置元件（先方案、后落图）

用户反馈：AI 拒绝布置元件（“没有数量或布置位置这类参数，我不能凭空生成布置类修改”）。要求改成
**先生成方案给用户过目，然后直接在图形化界面上布置出来**。

## 做法

核心约束没变：**Agent 不能编造坐标**。所以把“布置”拆成两层：

1. **模型只给意图**（`placements`）：元件 + 数量 + 选孔规则（region）+ 元件参数。
   提示词明确禁止输出坐标 / 方位角 / 第几行第几列，并要求“用户要求布置时必须给 placements，不许以缺坐标为由拒绝”。
2. **程序算落点**：`bundle/placement.pick_centers()` 按当次真实 `result.master_centers` 选孔；
   同一份方案重复执行结果一致。

新增/改动：
- `bundle/placement.py`（新）：`KIND_ALIASES`/`REGION_ALIASES`、`KIND_REGIONS`/`KIND_LIMITS`/`OPTION_FIELDS`、
  `parse_placements()`、`pick_centers()`、`describe_item()`。纯 Python，无 Qt 依赖，便于单测。
- `bundle/page.py`：`preview_placement(items)`（预估占用/剩余）+ `apply_placement_plan(items)`（统一落图）。
- `window.py`：`PlacementPlanCard`（方案卡）、`_show_placement_card/_confirm_placement/_discard_placement`、
  `_layout_state()`（给模型看管孔数与已布置统计，只读快照）、离线 `_parse_placement_words()`。
- `ai_support/api_client.py`：`parse_chat_payload` 解析 `placements`；`chat()` 增加 `layout_state` 入参与布置说明。

## 选孔算法（关键）

按极角把管孔分 `count` 瓣，每瓣取「半径最大 + 最贴近瓣中线」的一个：

```
score = (int(半径 / (最大半径*0.02)), -角度距离)
```

- 半径必须**先分档**再比角度。直接比 `hypot` 时，同一圈管孔因坐标 round 到 2 位小数会有 1e-5 级差异，
  第一关键字就把“角度均衡”盖掉了 —— 4 根拉杆会全挤在左右两侧（踩过这个坑）。
- 4 根 → 60°/131°/239°/311° 附近，四象限各一、都在最外圈，视觉上就是“均布靠壳壁”。

## 交互

- 方案卡：表格（元件/数量/位置规则/元件参数）+ 预计占用与剩余管孔 + 「放弃 / 确认布置」。
- 确认 → `apply_placement_plan` → 卡片转“已布置”并回显实际落点；自动滚回布管图形，能立刻看到元件。
- 聊天里说“确认布置 / 放弃方案”等价于点按钮；离线模式同样走方案卡（不再直接改图）。
- 模型万一还是不给 placements，只要用户那句确实是布置指令，就用本地规则补一版方案卡。
  纯咨询句（含“怎么/如何/吗/？”）不生成方案。

## 坑

- `current_centers()` 会把**所有**带 center 的元件都算占用；所以方案卡预估占用必须用
  `HOLE_OCCUPYING_KINDS`（含挡板/滑道/防冲板/径向孔），否则预估 0 实际 -4。
- 槽函数里抛异常时 Qt 直接吞掉，进程以 127 退出、无 traceback：`apply_placement_plan` 里
  `width/thickness` 未初始化就走进 else 分支，排查花了不少时间。已加 kind 白名单 + 变量兜底。
- `PlacementItem` 的 kind 必须过 `normalize_kind`：模型/离线给的是中文“拉杆”，直接构造会绕过白名单。

## 追加：防冲板三种形式按正式程序重建（圆弧形不是平板）

### 反馈
截图里选了“圆弧形”，图上画成一块平板 → 回去学 `impingement_plate.build_impingement_plate`，注意每个参数。

### 学到的正式构建（源码逐行）
| 形式 | 画法 | 关键参数 |
| --- | --- | --- |
| 平板形 | 一条**线宽=板厚**的粗线（pen 画线、不填充） | `放置位置`：顶部连线＝整段沿法向平移 `max(do/2,(do/2+板厚/2+0.5)/|ny|)`，**长度不变**；中心连线＝两端各内缩 `do/2`，长度=中心距−do |
| 圆弧形 | **A-P-Q-B 折边梯形**（开口朝圆心） | `防冲板折边角度` 15°–90°；`H=max(int(S)+1, int(do/2+6)+1)`；斜边 `L=H/sinθ`；顶部长度 `= 中心距 − 2H/tanθ`（<0 正式程序弹“参数异常”）；`P=A+u·(H/tanθ)+n·H`、`Q=P+u·top` |
| 焊接式 | C 点 + PQ + A/B 落在壳体大圆上 | `防冲板宽度`（PQ 长）、`防冲板方位角`（0°=顶部，正式程序 `270°+方位`）、`至圆筒内壁距离`（C 半径 = R−d）、`折边角度`（A/B 射线方向 `cosθ·径向 ∓ sinθ·PQ单位`，与 R 求交） |

- `build_arc_local_coordinate_system`：A/B = 两参照管圆心沿**局部 +y（垂直两管连线、指向圆外）**平移 `do/2+板厚/2`；端点顺序固定（小板坐标优先），反向选择同一对管子结果不翻转。
- 注意坐标：正式程序这些几何函数跑在**场景坐标（Qt，y 向下）**里，`_add(x,-y)` 是绘制时才翻。Demo 的布管数据是数学坐标 → `_impingement_geometry()` 里先 `(x,-y)` 进几何，`center` 再换回数学坐标。

### 实现
- 新增 `bundle/impingement.py`：`flat_points` / `arc_local_axes` / `folded_geometry` / `welded_geometry` / `geometry_for_form` / `required_span_for_folded` / `centroid`；非法参数抛 `ImpingementError`（对应正式程序弹窗那几种）。
- `bundle/items.py` 新增 `FoldedPlateItem`（QGraphicsPathItem，pen 宽度=板厚，深蓝 `QColor(0,0,139)`，不填充，z=16）。
- `bundle/page.py`：新增 `_impingement_geometry(form, pair)`；`place_impingement` 弹窗按形式联动显隐（放置位置只平板形、宽度/方位角/内壁距离只焊接式）；`_require_pairs` 拆成 `_pairs_from_centers(centers, what, max_span)`；`apply_placement_plan` 里防冲板单独一支（形式优先级：option > kind > 参数表）。
- `bundle/placement.py`：kind 细分为 `impingement`(平板) / `impingement_folded`(圆弧) / `impingement_welded`(焊接，0 参照管)；`PlacementItem.form` 属性；`IMPINGEMENT_FIELDS_BY_FORM` 让方案卡只显示该形式生效的参数；`pick_pairs(..., min_span=)`，圆弧形按 `2H/tanθ` 过滤并优先取“关于中心线对称”的那一对。
